# Documentation

Start with the [project README](../README.md) for an introduction and a first read-only task.
This directory contains guides for the use of `ghflow`.
Task procedures and shared rules in [`references/`](../references) own the current workflow instructions.

## Use ghflow

- [Setup](setup.md): Install the skill and supply source, repository, and project board access.
- [Operations](operations.md): Select a task for issues, pull requests, delivery, or project boards.
- [Project board views](board-views.md): Filters for triage, planning, and board health.
- [Issue interviews](issue-interview.md): How agents return decisions to the user conversation.
- [Writing rules](writing.md): The simplified-English rules for issue text, documents, and specifications.
- [Entry skill](../SKILL.md): Route an explicit request to a task reference.
- [CLI reference](../references/cli.md): Interpret PR state and commit inspection results.
